# ✅ Real-Time Task Management Application

A full-stack task management web app built with the **MERN Stack** that allows users to create, assign, and track tasks across different status columns — To-Do, In Progress, and Done.

---

## 🚀 Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React.js, React Hooks, CSS3 (Flexbox/Grid) |
| Backend | Node.js, Express.js, REST API |
| Database | MongoDB, Mongoose ODM |
| Architecture | MVC Pattern |
| Tools | Git, GitHub, Postman, VS Code |

---

## ✨ Features

- 📝 Create, Edit, and Delete Tasks
- 🔄 Drag-and-drop task status updates (To-Do → In Progress → Done)
- 🏷️ Priority levels: High, Medium, Low
- 📅 Deadline tracking per task
- 👥 Assign tasks to users
- 📊 Real-time status summary dashboard
- 📱 Responsive UI for all screen sizes

## 📡 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/tasks | Get all tasks |
| POST | /api/tasks | Create new task |
| PUT | /api/tasks/:id | Update task status |
| DELETE | /api/tasks/:id | Delete a task |
| GET | /api/tasks?status=todo | Filter by status |
